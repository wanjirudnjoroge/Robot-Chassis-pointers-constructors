# Task 2: Pointing at Something

This program demonstrates how pointers work in C++.

## Build & Run


g++ main.cpp -o main
./main


## What It Demonstrates

* Creating a pointer to a variable.
* Changing a variable through a pointer.
* Retargeting a pointer to another variable.
* Printing the pointer's address and value.

## Output

The program displays the values of `batteryPercent` and `wheelSpeed`, along with the memory addresses stored in the pointer.
