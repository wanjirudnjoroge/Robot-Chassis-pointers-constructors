# References

This task demonstrates how references can be used instead of pointers.

## Build & Run


g++ main.cpp -o main
./main


## Output


Reference doubling

before: y = 10
after: y = 20

Reference swap

before: p = 1, q = 2
after: p = 2, q = 1


## What It Demonstrates

References can change the original variable.

 doubleByReference() doubles y.

swapByReference() swaps two values.

References are simpler to use than pointers.
