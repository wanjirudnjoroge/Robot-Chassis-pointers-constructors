# Constructors

This task demonstrates different types of constructors in C++.

## Build & Run


g++ main.cpp -o main
./main


## Output


Motor ?: maxRpm = 0, enabled = 0
Motor R: maxRpm = 200, enabled = 1
Motor S: maxRpm = 150, enabled = 0


## What It Demonstrates

The program uses three constructors:

* A default constructor.
* A parameterized constructor.
* A constructor using a member initializer list.

Each constructor creates a `Motor` object with different values.
